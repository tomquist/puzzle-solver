# Test assets

Public-domain paintings used as reference images in automated tests
(downloaded from Wikimedia Commons, 1280 px thumbnails):

- `starry-night.jpg` – Vincent van Gogh, *The Starry Night* (1889). Public domain.
- `great-wave.jpg` – Katsushika Hokusai, *The Great Wave off Kanagawa* (c. 1831). Public domain.

They are only used by tests (`vitest`, Playwright) and are not shipped with the app.
